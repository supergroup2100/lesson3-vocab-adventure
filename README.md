# 🎃 萬聖節派對大冒險 (Lesson 3 Vocabulary Adventure)

專為國中七年級學生設計的 2D 橫向闖關單字學習網頁遊戲！

## 📖 遊戲特色
- **主題契合**：圍繞國中七年級英語 Lesson 3（美食餐具與萬聖節派對主題，共 35 個單字 + 1 句實用慣用語）。
- **三合一漸進式關卡**：
  - **第一關：美味廚房街道**（看英文／聽語音選中文意思）
  - **第二關：餐具城堡與派對邀約**（看中文選正確英文單字）
  - **第三關：萬聖節幽靈古宅**（課本例句挖空選擇題）
- **像素風格與 8-bit 音效**：復古橫向捲軸跳躍冒險、Web Audio 晶片音效與 Web Speech API 英文發音。
- **輕鬆學習向設計**：
  - 遇到問號門暫停觸發題目，答對開門前進，答錯即時顯示音標、中文與例句。
  - 生命值歸零時自動補滿回到安全點，不卡關、不挫折。
  - 結算畫面提供星等評分與錯題清單複習。
  - 支援電腦鍵盤與行動裝置/平板觸控按鈕操作。

## 🎮 操作方式
- **移動**：`←` `→` 或 `A` `D`
- **跳躍**：`空白鍵` (Space)、`↑` 或 `W`
- **答題後繼續**：`Enter` 或 `空白鍵` (Space)
- **觸控裝置**：畫面下方提供虛擬按鍵（◀、▶、JUMP）

## 🚀 執行方式
純前端技術（HTML5 Canvas + CSS + JavaScript），直接在瀏覽器中打開 `index.html` 即可遊玩，亦可部署至 GitHub Pages。
